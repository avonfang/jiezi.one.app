# 仙人指路：合规开关与部署说明

## 当前默认模式

默认不启用云端人脸匹配：

- `/zhixian` 网页只会随机生成演示结果；
- 用户选择的照片不读取内容、不上传服务器；
- 小程序 `pages/zhixian/zhixian` 也是纯前端随机演示；
- 页面不展示明星照片，不提供换脸 / 深度合成能力。

这样可以在未完成合规评估前安全试跑玩法与转化。

## 云端匹配模式（默认关闭）

如果确实要启用相似度接口，需要同时打开：

```bash
NEXT_PUBLIC_ZHIXIAN_FACE_MATCH_ENABLED=true
ZHIXIAN_FACE_MATCH_ENABLED=true
TENCENT_SECRET_ID=你的腾讯云SecretId
TENCENT_SECRET_KEY=你的腾讯云SecretKey
TENCENT_FACE_REGION=ap-guangzhou
TENCENT_FACE_GROUP_ID=zhixian_stars_v1
```

前端必须显式单独同意以下事项后才允许请求：

1. 用途仅限「风格相似度」娱乐匹配；
2. 不做人脸身份识别，不绑定账号或真实身份；
3. 照片会上传至芥子后端，并调用腾讯云人脸搜索接口；
4. 芥子应用侧不保存原图、不落库；
5. 不提供换脸 / 深度合成等生成能力；
6. 未成年人不提供本功能。

后端 `/api/zhixian/match` 会校验服务端开关与 `consentFaceSearch: true`，任一项缺失即返回 403。

## 风格档案库

构建脚本不会从外部网站拉取明星照片。所有档案图片必须先放在本机私有目录，并确认来源可用或已获授权：

```bash
ZHIXIAN_LIBRARY_DIR=/path/to/authorized-images node scripts/zhixian-build-library.mjs
```

文件命名：

- `shen_teng.jpg`
- `lei_jiayin.jpg`
- `yue_yunpeng.jpg`
- `jia_ling.jpg`
- `sha_yi.jpg`
- `bai_ke.jpg`

- [ ] 云端匹配开启前后均能看到“演示结果 / 云端结果”标识。

## 完整指路卡解锁接口

小程序端已接入真实积分扣减：

- 接口：`POST /api/zhixian/unlock`
- 默认价格：6 积分
- 可用环境变量覆盖：`ZHIXIAN_UNLOCK_CREDIT_COST`
- 请求体：`{ "resultId": "16位结果指纹" }`
- 同一用户 + 同一 `resultId` 只扣一次积分；重复请求返回成功且余额不变。
- 积分不足返回 `402` 与 `INSUFFICIENT_CREDITS`。
- 小程序端会同步展示余额、价格、不足提示和充值入口。

`resultId` 由小程序根据 Top 3 风格结果和城市生成，只包含结果指纹，不包含照片或个人生物信息。

## 部署前锁文件注意

本次新增 `tencentcloud-sdk-nodejs` 运行依赖，并生成 `pnpm-lock.yaml`。仓库中仍保留历史 `package-lock.json`，部署前需要统一包管理器：

- 若继续使用 pnpm / Vercel 自动识别 pnpm：提交 `pnpm-lock.yaml`，确认部署命令使用 pnpm。
- 若继续使用 npm：需要重新生成 `package-lock.json`，确保腾讯云 SDK 及其传递依赖进入 npm 锁文件。

不要同时把两个锁文件当作“都已同步”的依据。
